## UltraDim 0.4.0 — compiled wheels, three platforms

UltraDim is an analytical vector database for ultra-wide data, shipped as a compiled Python wheel. The database runs in-process: no server, no port.

```python
import ultradim
db = ultradim.UltraDim("./db")
print(len(db.capabilities()))   # 204 RPCs, all reachable via db.call_json(...)
```

### What is in this release

- The engine is identical to 0.3.12: 204 RPCs, 46 MCP tools, no behaviour change.
- The wheel now carries its licence inside the package at `ultradim/LICENSES/`. Earlier wheels shipped no terms.

### Install

Python 3.12 only. Pick the wheel for your platform and install it by path; numpy comes with it:

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install ./UltraDim-0.4.0-cp312-cp312-macosx_11_0_arm64.whl        # macOS, Apple silicon
pip install ./UltraDim-0.4.0-cp312-cp312-manylinux_2_28_x86_64.whl     # Linux x86_64, glibc 2.28+
pip install ./UltraDim-0.4.0-cp312-cp312-manylinux_2_28_aarch64.whl    # Linux arm64, glibc 2.28+
```

A GPU is used when one is reachable (Metal on macOS, Vulkan on Linux). Without one the database still runs, slower on clustering and index builds.
