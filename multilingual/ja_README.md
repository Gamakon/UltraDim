# UltraDim

**極端な次元数のデータセットのための、高速な分析用ベクトルストアです。**<br>
**3,000 万次元で実証済み、10 億次元を目指しています。**

*本文書は[英語版 README](../README.md) の日本語訳です。パスとリンクはリポジトリ内のファイルを指しています。*

*初めての方へ：[技術者でない方へ：高次元の疎データとは何でしょうか？](ja_WHAT_IS_HIGH_DIMENSIONAL_SPARSE_DATA.md)*

UltraDim は、従来のベクトルデータベースの次元数の限界をはるかに超えて、ベクトルの保存、検索、マップ化、分類、クラスタリングを行います。密ベクトルは約 256,000 次元まで、疎ベクトルは数千万次元まで対応し、実際の化学コーパスを用いた本番運用で **30,000,000 次元**での動作が実証されており、1 億次元でのデモンストレーションも行っています。Rust で実装され、macOS では Metal、Linux では Vulkan による GPU アクセラレーションを備え、Python から操作します。

UltraDim は、Apple シリコン搭載 macOS、Linux x86_64、Linux arm64 向けに、Python 3.12 用のコンパイル済み Python パッケージ（wheel）として配布されます。現行リリースは 0.4.0 で、[Releases](../../../releases) ページから入手できます。非商用利用は PolyForm Noncommercial License 1.0.0 のもとで無償です。商用利用には Gamakon Ltd のライセンスが必要です。ライセンス本文は [`LICENSE`](../LICENSE)、両方の形態を説明した通知は [`LICENSES/LICENSE.md`](../LICENSES/LICENSE.md) にあります。

## 機能

- **本来の幅でのインジェスト**（幅とは次元数のことです） — 密ベクトルは約 256,000 次元まで、疎ベクトルは数千万次元まで（3,000 万次元で実証済み、1 億次元でデモンストレーション済み）。メモリ使用量は宣言した幅ではなく、非ゼロ要素の数に応じて増加します
- **自己検証型の検索** — 正確な真のコサインスコアを返し、要求に応じて厳密な総当たり検索と照合したリコール証明書を発行します
- **高スループットの密ベクトル検索** — DBpedia-1M において p50 2.99 ms で毎秒 1,339 クエリ、precision@10 = 0.9945
- **ネイティブな UMAP マップ** — 任意の幅で、決定論的かつキャッシュされたサーバー側のフィット。新しい点はミリ秒単位で配置され、増分再フィットは再構築コストの約 1.5% で済みます。出力は 2 次元、中間次元（最大 256 成分）、または球面です
- **品質しきい値付きの k-NN グラフ構築** — すべてのグラフに実測のリコール値が付随し、0.99 未満のグラフに対してマップはフィットを拒否します
- **任意の幅でのクラスタリング** — GPU 常駐の球面 k-means と階層クラスタリングを備え、次元補正済みの品質スコアにより幅の異なるデータ間でも比較できます
- **ストリーミング新規性検出** — 到着データを既存の高次元最近傍構造と照合してスコアリングし、生きた UMAP 上に配置することで、異常な集団や新たに出現した集団を可視化します。下のストリーミングの図は、マップ変換 RPC を用いた短いスクリプトによるものです
- **因子分解と推薦** — 保留した値をインデックスから直接デコードします。パラメータ不要の近傍法で、公開ベンチマークにおいて学習済みベースラインと競合する性能です
- **合成データサービス** — 一様な超球面バンクと、不均衡データセット向けの k-NN による少数クラス増強
- **BloomMap 可視化** — 階層クラスタリングの出版品質のポスターレンダリング
- **データ操作** — CSV、JSON、バイナリ形式へのエクスポート、コレクション分析、サーバー内テキスト埋め込み
- **3 つの実行形態** — Python wheel として自身のプロセス内で実行、アシスタント向けの MCP サーバーとして実行、または多数のクライアントがポート経由で gRPC によりアクセスする共有サーバーとして実行（要相談）。3 形態すべてで同じ 204 の RPC が使えます
- **一貫した来歴管理** — バージョン管理されたパラメータ、シード、行の記録、エクスポート可能な結果により、あらゆる分析出力を検証し再現できます

## 入手方法

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install ./UltraDim-0.4.0-cp312-cp312-macosx_11_0_arm64.whl      # numpy は同梱されます
```

```python
import ultradim
db = ultradim.UltraDim("./db")
print(len(db.capabilities()))          # 204
db.call_json("RpcName", '{...}')       # いずれの RPC でも
```

データベースはご自身のプロセス内で動作します。起動すべきサーバーも、開くべきポートもありません。GPU があれば使用されます（macOS では Metal、Linux では Vulkan）。GPU がなくても、UltraDim は疎データと密データの読み込み、インデックス作成、検索、近傍グラフと密度系統の構築、リコールの測定を行います。UMAP のフィット、k-means クラスタリング、k-means 系統には GPU が必要で、GPU がない場合はエラーを返します。測定結果は [`docs/GPU_SETTINGS.md`](../docs/GPU_SETTINGS.md) にあります。

MCP サーバー `mcp/ultradim_mcp_server_v0_4_0.py` は、同じ wheel を 46 のツールとしてラップしており、アシスタントが Python を書くことなくコレクションの作成、インジェスト、インデックス作成、検索、クラスタリング、マップ化を行えます。ガイドは [`mcp/README.md`](../mcp/README.md) です。

クライアント・サーバー版もあります。1 台のホスト上で UltraDim サーバーが稼働し、多数のクライアントがポート経由で共有します。クライアントは gRPC で書き込みとクエリを行います。gRPC はコンパクトなバイナリプロトコルなので、幅の広いベクトルのインジェストもネットワーク上で高速です。wheel と同じエンジンで、同じ 204 の RPC を備えています。入手をご希望の方はご連絡ください。必要とする非商用組織も対象で、インストールと設定をお手伝いします。jesung@gamakon.ai または andrew@gamakon.ai までどうぞ。

## AI アシスタントで実行する

このリポジトリには MCP サーバー `mcp/ultradim_mcp_server_v0_4_0.py` が同梱されており、データベースを 46 のツールとして Claude Code、Codex、その他 MCP に対応した任意のアシスタントに公開します。アシスタントはあなたに代わってデータベースを操作します。ファミリーを作成し、ベクトルをインジェストし、インデックスを構築し、検索、クラスタリング、マップ化を行い、結果を読み上げます。あなたが研究内容を説明し、アシスタントが呼び出しを行います。

wheel をインストールし、このリポジトリをクローンして、クローン内でアシスタントのセッションを開いてください。Claude Code の場合はルートにある `.mcp.json` がサーバーを登録します。Codex の場合は `~/.codex/config.toml` に次を追加してください。

```toml
[mcp_servers.ultradim]
command = "python3.12"
args = ["/path/to/UltraDim/mcp/ultradim_mcp_server_v0_4_0.py", "--db", "/path/to/your/db"]
```

`command` には wheel がインストールされている Python を指定する必要があります。あとは言葉で、「このファイルのベクトルを UltraDim に読み込んで、検索できるようにして、マップを見せて」と頼むだけです。アシスタントの最初の呼び出しは `whats_available` ツールであるべきで、これは wheel から直接、すべてのツールと標準的な手順を一覧します。完全なガイドは [`mcp/README.md`](../mcp/README.md)（英語）です。

## できること

**超広幅データを検索し、その答えを信頼する。** UltraDim は、分子フィンガープリント、小売のバスケット、one-hot 符号化したゲノミクス、テキスト埋め込みなど、データを本来の幅のまま扱います。利用者側での特徴量ハッシングや切り詰めは不要です。返されるスコアは元のベクトルに対する真のコサインであり、インデックスは要求に応じて厳密な総当たりの答えと照合して自らの候補リコールを測定します。そのため、すべてのコーパスには「期待」ではなく品質証明書が付いてきます。

**3,000 万次元データの生きた 2 次元マップを構築する。** UMAP マップはサーバー上でネイティブに計算されるため、標準的なツールではデータの読み込みすらできない幅でもマップ構築が機能します。マップは生きたオブジェクトです。新しい点は既存のマップ上にミリ秒単位で配置され、小さなバッチは再構築コストの約 1.5% で取り込まれ、マップのバージョン履歴はデータストリームのドリフト検出器としても機能します。

**任意の幅でクラスタリングし、スコアリングする。** 球面 k-means と階層クラスタリングは、極端な次元数でも GPU 常駐で動作し、次元補正済みの品質スコアは幅が異なっても比較可能なままです。そのため、「このクラスタリングは本物か」という問いに、300 次元だけでなく 3,000 万次元でも統計的な答えが得られます。

**幅と闘うのではなく、幅を活かす分析を行う。** フィット済みマップ上での到着データの新規性スコアリング、保留した値をインデックスから直接デコードする因子分解、合成データ生成と少数クラス増強、コレクション分析、下流ツール向けのエクスポート。

## 実測性能

すべての数値は、単一の Apple M3 Max 上で、厳密な総当たりオラクルと照合した管理された実験実行によるもので、品質とレイテンシを併せて報告しています。

| コーパス | 幅 | 行数 | 品質 | レイテンシ / スループット |
|---|---|---|---|---|
| ChEMBL 分子（疎） | 30,000,000 | 500,000 | recall@10 = 0.9992 | 1 クエリあたり 56 ms |
| ChEMBL 分子（疎、高速プロファイル） | 30,000,000 | 500,000 | recall@10 = 0.9964 | 1 クエリあたり 29 ms |
| DBpedia 埋め込み（密） | 1,536 | 1,000,000 | precision@10 = 0.9945 | p50 2.99 ms で毎秒 1,339 クエリ |
| 小売バスケット（疎） | 100,000 | 100,000 | recall@10 = 0.9851 | p50 17.5 ms |
| 合成構造化データ（疎） | 1,800,000 | 50,000 | recall@10 = 1.000 | p50 15.7 ms |

幅のコストはわずかです。コーパスを 100 万次元から 1,000 万次元に広げても常駐メモリの増加は約 0.08 GiB です。疎ストレージは宣言した幅ではなく、非ゼロ要素の数に応じて増加するためです。

### 誕生の経緯

*どのようにして生まれたか*

UltraDim データベースの内部では、*Mastering Spark for Data Science* の著者である Andrew Morgan が開発した、まったく新しい形式のベクトルインデックスを使用しています。彼は ARC-AGI チャレンジを解くための自身のアイデアを構築し検証するためにこのインデックスを考案しました。その取り組みは現在も続いています。

30 年にわたるデータサイエンスエンジニアリングの経験を活かし、Andrew は数多くの最適化を施してこれを実装しました。新しいインデックスと相まって、これらの最適化により、大規模な Spark クラスターを Mac のノートパソコン 1 台で置き換えることができます。

Andrew は AI の助けを借りましたが、それは極めてもどかしい経験だったと語っています。「AI は革新を嫌います。このインデックス設計を一度も見たことがなかったため、有用な貢献をすることに終始苦労し、しばしば意図的にコードを古いアイデアへと戻してしまいました。」一年にわたる粘り強い苦闘の末に得られたのは、私たちが心から誇りに思うシステムです。ぜひお楽しみいただき、何か素晴らしいものを作るために使っていただければ幸いです。
