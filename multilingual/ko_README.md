# UltraDim

**극단적 차원의 데이터셋을 위한 고속 분석형 벡터 저장소입니다.**<br>
**3천만 차원에서 검증되었으며, 10억 차원을 목표로 합니다.**

*이 문서는 [영어 README](../README.md)의 한국어 번역본입니다. 경로와 링크는 저장소의 파일을 가리킵니다.*

*처음이십니까? [비전문가를 위한 설명: 고차원 희소 데이터란 무엇입니까?](ko_WHAT_IS_HIGH_DIMENSIONAL_SPARSE_DATA.md)*

UltraDim은 기존 벡터 데이터베이스의 차원 한계를 훨씬 뛰어넘어 벡터를 저장, 검색, 지도화, 분류, 군집화합니다. 밀집(dense) 데이터는 약 256,000차원까지, 희소(sparse) 데이터는 수천만 차원까지 처리하며, 실제 화학 코퍼스에 대한 프로덕션 실행에서 **30,000,000차원**으로 검증되었으며, 1억 차원에서 시연되었습니다. Rust로 작성되었고, macOS에서는 Metal, Linux에서는 Vulkan을 통해 GPU 가속을 받으며, Python에서 구동됩니다.

UltraDim은 Apple silicon macOS, Linux x86_64, Linux arm64용으로 Python 3.12에 맞춰 컴파일된 Python wheel(파이썬 배포 패키지)로 제공됩니다. 현재 릴리스는 0.4.0이며, [Releases](../../../releases) 페이지에서 받을 수 있습니다. 비상업적 사용은 PolyForm Noncommercial License 1.0.0에 따라 무료입니다. 상업적 사용에는 Gamakon Ltd의 라이선스가 필요합니다. 라이선스 본문은 [`LICENSE`](../LICENSE)이고, 두 가지 사용 방식을 설명하는 안내문은 [`LICENSES/LICENSE.md`](../LICENSES/LICENSE.md)입니다.

## 기능

- **원래 폭 그대로의 적재**(폭이란 차원의 수를 뜻합니다) — 밀집 벡터는 약 256,000차원까지, 희소 벡터는 수천만 차원까지(3천만 차원 검증, 1억 차원 시연) 처리하며, 메모리는 선언한 폭이 아니라 0이 아닌 값의 수에 비례합니다
- **자가 검증 검색** — 정확한 참 코사인 점수를 제공하며, 요청 시 정확한 전수 탐색(brute force)과 대조하여 측정한 재현율(recall) 인증서를 발급합니다
- **고처리량 밀집 검색** — DBpedia-1M에서 초당 1,339 질의, p50 2.99 ms, precision@10 = 0.9945
- **네이티브 UMAP 지도** — 어떤 폭에서든 결정론적이고 캐시되는 서버 측 적합(fit); 새 점은 밀리초 단위로 배치; 재구축 비용의 약 1.5%로 증분 재적합; 2차원, 중간 차원(최대 256 성분), 또는 구면 출력
- **품질 임계값을 갖춘 k-NN 그래프 구축** — 모든 그래프에 측정된 재현율 수치가 딸려 있으며, 0.99 미만인 그래프에서는 지도 적합을 거부합니다
- **어떤 폭에서든 군집화** — GPU 상주형 구면 k-means 및 계층적 군집화, 폭이 달라도 비교 가능한 차원 보정 품질 점수 제공
- **스트리밍 신규성 탐지** — 새로 도착하는 데이터를 기존 고차원 최근접 이웃 구조와 대조해 점수화한 뒤 살아 있는 UMAP 위에 배치하여 이상 집단과 신흥 집단이 눈에 보이게 합니다. 아래의 스트리밍 그림은 지도 변환 RPC 위에서 동작하는 짧은 스크립트로 만든 것입니다
- **인수분해와 추천** — 보류(held-out) 값을 인덱스에서 직접 복원하며, 공개 벤치마크에서 학습 기반 기준선과 경쟁하는 파라미터 없는 이웃 기반 방법을 제공합니다
- **합성 데이터 서비스** — 불균형 데이터셋을 위한 균일 초구(hypersphere) 은행과 k-NN 소수 클래스 증강
- **BloomMap 시각화** — 계층적 군집화 결과를 출판 수준의 포스터로 렌더링
- **데이터 연산** — CSV, JSON, 바이너리 형식으로 내보내기; 컬렉션 분석; 서버 내 텍스트 임베딩
- **세 가지 실행 방식** — 사용자의 프로세스 안에서 Python wheel로; 어시스턴트를 위한 MCP 서버로; 또는 여러 클라이언트가 포트를 통해 gRPC로 접속하는 공유 서버로(요청 시 제공). 세 방식 모두 동일한 204개의 RPC를 제공합니다
- **전 과정의 출처 추적** — 버전 관리되는 파라미터, 시드, 행 회계, 내보낼 수 있는 결과를 통해 모든 분석 출력을 검토하고 재현할 수 있습니다

## 설치

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install ./UltraDim-0.4.0-cp312-cp312-macosx_11_0_arm64.whl      # numpy comes with it
```

```python
import ultradim
db = ultradim.UltraDim("./db")
print(len(db.capabilities()))          # 204
db.call_json("RpcName", '{...}')       # any of them
```

데이터베이스는 사용자의 프로세스 안에서 실행됩니다. 시작할 서버도, 열어야 할 포트도 없습니다. GPU가 있으면 사용합니다(macOS에서는 Metal, Linux에서는 Vulkan). GPU가 없어도 UltraDim은 희소 및 밀집 데이터를 적재, 색인, 검색하고, 이웃 그래프와 밀도 계보(lineage)를 구축하며, 재현율을 측정합니다. UMAP 적합, k-means 군집화, k-means 계보에는 GPU가 필요하며 GPU가 없으면 오류를 반환합니다. 측정 결과는 [`docs/GPU_SETTINGS.md`](../docs/GPU_SETTINGS.md)에 있습니다.

MCP 서버 `mcp/ultradim_mcp_server_v0_4_0.py`는 동일한 wheel을 46개의 도구로 감싸므로, 사용자가 Python을 작성하지 않아도 어시스턴트가 컬렉션 생성, 적재, 색인, 검색, 군집화, 지도화를 수행할 수 있습니다. 안내서는 [`mcp/README.md`](../mcp/README.md)입니다.

클라이언트-서버 버전도 제공됩니다. 하나의 UltraDim 서버가 호스트에서 실행되고 여러 클라이언트가 포트를 통해 이를 공유합니다. 클라이언트는 gRPC로 쓰기와 질의를 수행합니다. gRPC는 간결한 바이너리 프로토콜이므로 넓은 벡터의 적재가 네트워크상에서 빠릅니다. wheel과 동일한 엔진이며, 동일한 204개의 RPC를 제공합니다. 필요하시면 연락해 주십시오. 이는 이 버전이 필요한 비상업적 기관도 포함하며, 설치와 설정을 도와드릴 수 있습니다. jesung@gamakon.ai 또는 andrew@gamakon.ai.

## AI 어시스턴트와 함께 실행하기

이 저장소에는 MCP 서버 `mcp/ultradim_mcp_server_v0_4_0.py`가 포함되어 있으며, 데이터베이스를 46개의 도구로서 Claude Code, Codex, 또는 MCP를 지원하는 모든 어시스턴트에 노출합니다. 그러면 어시스턴트가 사용자를 대신해 데이터베이스를 운용합니다. 패밀리를 생성하고, 벡터를 적재하고, 인덱스를 구축하고, 검색, 군집화, 지도화를 수행한 뒤 결과를 읽어 알려 줍니다. 사용자는 연구를 설명하고, 어시스턴트가 호출을 수행합니다.

wheel을 설치하고, 이 저장소를 복제한 뒤, 복제본 안에서 어시스턴트 세션을 여십시오. Claude Code의 경우 루트의 `.mcp.json`이 서버를 등록합니다. Codex의 경우 `~/.codex/config.toml`에 다음을 추가하십시오.

```toml
[mcp_servers.ultradim]
command = "python3.12"
args = ["/path/to/UltraDim/mcp/ultradim_mcp_server_v0_4_0.py", "--db", "/path/to/your/db"]
```

`command`는 wheel이 설치된 Python이어야 합니다. 그런 다음 말로 요청하십시오. "이 파일의 벡터를 UltraDim에 적재하고, 검색 가능하게 만든 다음, 지도를 보여 주십시오." 어시스턴트의 첫 호출은 `whats_available` 도구여야 하며, 이 도구는 모든 도구와 권장 경로(happy path)를 wheel에서 직접 나열합니다. 전체 안내서는 [`mcp/README.md`](../mcp/README.md)입니다(영어).

## 무엇을 할 수 있는가

**초광폭 데이터를 검색하고, 그 답을 신뢰할 수 있습니다.** UltraDim은 분자 지문, 소매 장바구니, 원-핫 유전체 데이터, 텍스트 임베딩 등 사용자의 데이터를 원래 폭 그대로 다루며, 사용자 측의 특징 해싱이나 절단이 필요 없습니다. 반환되는 점수는 원본 벡터에 대한 참 코사인 값이고, 인덱스는 요청 시 정확한 전수 탐색 답과 대조하여 자신의 후보 재현율을 측정하므로, 모든 코퍼스는 막연한 기대가 아니라 품질 인증서와 함께 제공됩니다.

**3천만 차원 데이터의 살아 있는 2차원 지도를 구축합니다.** UMAP 지도는 서버에서 네이티브로 계산되므로, 표준 도구로는 데이터를 로드조차 할 수 없는 폭에서도 지도 구축이 가능합니다. 지도는 살아 있는 객체입니다. 새 점은 기존 지도 위에 밀리초 단위로 배치되고, 소규모 배치는 재구축 비용의 약 1.5%로 병합되며, 지도의 버전 이력은 데이터 스트림의 편차(drift) 탐지기 역할도 합니다.

**어떤 폭에서든 군집화하고 점수를 매깁니다.** 구면 k-means와 계층적 군집화는 극단적 차원에서도 GPU 상주형으로 실행되며, 폭이 달라도 비교 가능한 차원 보정 품질 점수를 제공합니다. 따라서 "이 군집화가 실재하는가?"라는 질문에 300차원뿐 아니라 3천만 차원에서도 통계적 답을 얻을 수 있습니다.

**폭과 싸우는 대신 폭을 활용하는 분석을 수행합니다.** 적합된 지도 위에서 새로 도착한 데이터의 신규성 점수화; 보류 값을 인덱스에서 직접 복원하는 인수분해; 합성 데이터 생성과 소수 클래스 증강; 컬렉션 분석; 후속 도구를 위한 내보내기.

## 측정된 성능

모든 수치는 단일 Apple M3 Max에서 정확한 전수 탐색 오라클과 대조한 통제 실험에서 얻은 것이며, 품질과 지연 시간을 함께 보고합니다.

| 코퍼스 | 폭 | 행 수 | 품질 | 지연 시간 / 처리량 |
|---|---|---|---|---|
| ChEMBL 분자 (희소) | 30,000,000 | 500,000 | recall@10 = 0.9992 | 질의당 56 ms |
| ChEMBL 분자 (희소, 고속 프로파일) | 30,000,000 | 500,000 | recall@10 = 0.9964 | 질의당 29 ms |
| DBpedia 임베딩 (밀집) | 1,536 | 1,000,000 | precision@10 = 0.9945 | 초당 1,339 질의, p50 2.99 ms |
| 소매 장바구니 (희소) | 100,000 | 100,000 | recall@10 = 0.9851 | p50 17.5 ms |
| 합성 구조화 데이터 (희소) | 1,800,000 | 50,000 | recall@10 = 1.000 | p50 15.7 ms |

폭의 비용은 적습니다. 코퍼스를 100만 차원에서 1,000만 차원으로 늘려도 상주 메모리는 약 0.08 GiB만 증가하는데, 희소 저장소가 선언한 폭이 아니라 0이 아닌 값의 수에 비례하기 때문입니다.

## 연구 그룹과의 협력

UltraDim은 분자 표현, 유전체 및 후성유전체 프로파일, 대규모 관측 행렬 등 실제 과학 워크로드에 연구 그룹이 사용하고 있습니다. 연구 목적 사용은 비상업 라이선스에 따라 무료이므로, wheel을 내려받아 바로 시작하십시오. 좋은 프로젝트는 고차원이거나, 크거나, 희소하거나, 현재 도구로는 분석이 느린 코퍼스와, 근거 있는 벡터 표현 및 거리 척도와, 검색, 코호트, 군집화, 또는 시각화에 관한 질문을 갖추고 있습니다.
