# UltraDim

**தீவிர பரிமாணத் தரவுத்தொகுப்புகளுக்கான வேகமான பகுப்பாய்வு வெக்டர் தரவுத்தளம் (Analytical Vector Store).**<br>
**30 மில்லியன் பரிமாணங்களில் நிரூபிக்கப்பட்டது; இலக்கு ஒரு பில்லியன் பரிமாணங்கள்.**

UltraDim, Apple silicon-இல் macOS, Linux x86_64 மற்றும் Linux arm64 ஆகியவற்றுக்கு, Python 3.12-க்கான தொகுக்கப்பட்ட Python wheel-ஆக வழங்கப்படுகிறது. தற்போதைய வெளியீடு 0.4.0; இது [Releases](../../../releases) பக்கத்தில் உள்ளது. வணிகமற்ற பயன்பாடு PolyForm Noncommercial License 1.0.0-இன் கீழ் இலவசம். வணிகப் பயன்பாட்டிற்கு Gamakon Ltd-இடமிருந்து உரிமம் தேவை. உரிம உரை [`LICENSE`](../LICENSE); இரு வழிகளையும் விளக்கும் அறிவிப்பு [`LICENSES/LICENSE.md`](../LICENSES/LICENSE.md).

## அம்சங்கள்

- **அதி-பரிமாணத் தரவு ஏற்றுதல்** — பெரிய அடர்த்தியான வெக்டர்களை உள்ளீடு (ingest) செய்யலாம், ~256,000 பரிமாணங்கள் வரை சோதிக்கப்பட்டது; அல்லது பெரிய விரல்விட்ட வெக்டர்களை, 30M வரை சோதிக்கப்பட்டது, 100M செயல்விளக்கம் செய்யப்பட்டது. உங்கள் RAM மற்றும் வட்டுத் தேவைகள் மூல வெக்டர் அளவுடன் அல்ல, உங்கள் பூச்சியமற்ற மதிப்புகளுடன் (non-zeros) அளவிடுகின்றன.
- **தன்னைத் தானே சரிபார்க்கும் தேடல்** — துல்லியமான உண்மையான cosine மதிப்பெண்கள்; தேவைப்படும்போது, துல்லியமான முழுத் தேடலுக்கு (brute force) எதிராக அளவிடப்பட்ட recall சான்றிதழ்கள்
- **அதிக செயல்திறன் கொண்ட அடர்த்தியான தேடல்** — DBpedia-1M-இல் p50 2.99 ms-இல் 1,339 வினவல்கள்/வினாடி, precision@10 = 0.9945
- **இயல்பான UMAP வரைபடங்கள்** — மிகைப் பரிமாணத் தரவுத் தொகுப்புகளுக்கான நிர்ணயமான, தற்காலிகச் சேமிப்பில் வைக்கப்பட்ட, விரைவான UMAP செயலாக்கம். முன்பு காணாத புதிய புள்ளிகள் மில்லிவினாடிகளில் மதிப்பிடப்படுகின்றன; மறுகட்டமைப்புச் செலவின் ~1.5%-இல் படிப்படியான மறுபொருத்தம் உள்ளடங்கியது; காட்சிப்படுத்தலையும் பரிமாணக் குறைப்பையும் ஆதரிக்கும் 2-D முதல் 256-D வரையிலான வெளியீடுகள்.
- **தர வரம்புகளுடன் k-NN வரைகட்டமைப்பு (graph) உருவாக்கம்** — ஒவ்வொரு வரைகட்டமைப்பும் அளவிடப்பட்ட recall எண்ணைக் கொண்டிருக்கும்; 0.99-க்குக் கீழுள்ள வரைகட்டமைப்புகளின் மீது வரைபடங்கள் பொருத்த மறுக்கின்றன
- **அதி-பரிமாணத் தரவுக்கான கொத்தாக்கம் (clustering), 30 மில்லியன் பரிமாணங்களிலும்** — GPU-இல் தங்கியிருக்கும் கோள k-means மற்றும் படிநிலைக் கொத்தாக்கம், அகலங்களுக்கிடையே ஒப்பிடத்தக்க, பரிமாணத் திருத்தம் செய்யப்பட்ட தர மதிப்பெண்களுடன்
- **ஓட்டநிலை உயர்-பரிமாண முரண்பாடு கண்டறிதல் (streaming high-d anomaly detection)** — புதிதாக வரும் புள்ளிகளை, ஏற்கனவே உள்ள உயர்-பரிமாண அண்மை-அயலார் (nearest-neighbour) கட்டமைப்புக்கு எதிராக மதிப்பிட்டு, பின்னர் அவற்றை ஒரு உயிருள்ள UMAP-இல் இடம்பெறச் செய்வதால், அசாதாரணமான மற்றும் புதிதாக எழும் தொகுதிகள் கண்ணுக்குத் தெரிகின்றன; கீழேயுள்ள ஓட்டநிலைப் படம், வரைபட-மாற்று (map-transform) RPC-இன் மீதான ஒரு சிறிய script
- **காரணியாக்கமும் (factorisation) பரிந்துரையும்** — ஒதுக்கிவைக்கப்பட்ட மதிப்புகளை நேரடியாக அட்டவணையிலிருந்து (index) மீட்டெடுத்தல்; பொது அளவுகோலில் பயிற்றுவிக்கப்பட்ட அடிப்படை முறைகளுடன் போட்டியிடும், அளவுருக்கள் இல்லாத அயலகம் (neighbourhood) சார்ந்த முறை
- **மிகைக்கோளங்களில் செயற்கைத் தரவை உருவாக்குதல்** — நமது தரவுக் குறியீடு அமைந்துள்ள மிகைக்கோள (hypersphere) மேற்பரப்பில் Muller-Marsaglia முறைப்படி சீரான புள்ளிகளை wgpu மூலம் உருவாக்கும் வசதியை இக்குறியீடு வழங்குகிறது. ஒரு உண்மையான புள்ளியின் சிறுபான்மைக் குறியீட்டை (label) அதற்கு மிக அருகிலுள்ள k செயற்கை அண்டைப் புள்ளிகளுக்குப் பொருத்துவதன் மூலம் தரவுத்தொகுப்புகளை மறுசமநிலைப்படுத்தும் ஒரு சோதனை முறையின் பகுதி இது.
- **BloomMap காட்சிப்படுத்தல்** — படிநிலைக் கொத்தாக்கங்களின் வெளியீட்டுத் தரமான சுவரொட்டி (poster) வரைதல்
- **தரவுச் செயல்பாடுகள்** — CSV, JSON மற்றும் ஒரு இரும (binary) வடிவத்திற்கு ஏற்றுமதி; தொகுப்புப் (collection) பகுப்பாய்வு; சேவையகத்திற்குள்ளேயே உரை உட்பொதிவு (text embedding)
- **இயக்க மூன்று வழிகள்** — Python wheel-ஆக உங்கள் சொந்த செயல்முறைக்குள்; ஒரு உதவியாளருக்கான (assistant) MCP சேவையகமாக; அல்லது ஒரு port வழியாக பல வாடிக்கையாளர்கள் gRPC மூலம் அணுகும் பகிரப்பட்ட சேவையகமாக, கோரிக்கையின் பேரில் கிடைக்கும். மூன்றிலும் அதே 204 RPC-கள்.
- **முழுவதும் மூலத்தடம் (provenance)** — பதிப்பிடப்பட்ட அளவுருக்கள், விதைகள் (seeds), வரிசைக் கணக்கீடு, மற்றும் ஏற்றுமதி செய்யக்கூடிய முடிவுகள்; இதனால் ஒவ்வொரு பகுப்பாய்வு வெளியீட்டையும் ஆய்வு செய்யவும் மீண்டும் செய்யவும் முடியும்

## பெறுவது எப்படி

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install ./UltraDim-0.4.0-cp312-cp312-macosx_11_0_arm64.whl      # numpy comes with it
```

```python
import ultradim
db = ultradim.UltraDim("./db")
print(len(db.capabilities()))          # 204
db.call_json("RpcName", '{...}')       # any of them
```

தரவுத்தளம் உங்கள் செயல்முறைக்குள்ளேயே இயங்குகிறது. தொடங்க வேண்டிய சேவையகமோ, திறக்க வேண்டிய port-ஓ இல்லை. GPU இருந்தால் அது பயன்படுத்தப்படும் (macOS-இல் Metal, Linux-இல் Vulkan). GPU இல்லாமலும், UltraDim விரல்விட்ட மற்றும் அடர்த்தியான தரவை ஏற்றுகிறது, அட்டவணையிடுகிறது, தேடுகிறது; அயலார் வரைகட்டமைப்புகளையும் அடர்த்திப் பரம்பரைகளையும் (density lineages) உருவாக்குகிறது; recall-ஐ அளவிடுகிறது. UMAP பொருத்தங்கள், k-means கொத்தாக்கம் மற்றும் k-means பரம்பரைகள் ஆகியவற்றுக்கு GPU தேவை; அது இல்லாவிட்டால் பிழை திரும்பும். அளவீடுகள் [`docs/GPU_SETTINGS.md`](../docs/GPU_SETTINGS.md)-இல் உள்ளன.

ஒரு MCP சேவையகம், `mcp/ultradim_mcp_server_v0_4_0.py`, அதே wheel-ஐ 46 கருவிகளாகச் சுற்றி வழங்குகிறது; இதனால் நீங்கள் Python எழுதாமலேயே ஒரு உதவியாளர் தொகுப்புகளை உருவாக்கவும், உள்ளீடு செய்யவும், அட்டவணையிடவும், தேடவும், கொத்தாக்கவும், வரைபடமாக்கவும் முடியும். அதன் வழிகாட்டி [`mcp/README.md`](../mcp/README.md).

ஒரு வாடிக்கையாளர்-சேவையக (client-server) பதிப்பும் கிடைக்கிறது. ஒரு UltraDim சேவையகம் ஒரு புரவலனில் (host) இயங்கி, ஒரு port வழியாக பல வாடிக்கையாளர்களால் பகிரப்படுகிறது. வாடிக்கையாளர்கள் gRPC மூலம் எழுதுகிறார்கள், வினவுகிறார்கள். gRPC ஒரு சுருக்கமான இரும நெறிமுறை (protocol) என்பதால், அகலமான வெக்டர்களின் உள்ளீடு பிணையத்தில் வேகமாக நடக்கிறது. இது wheel-இன் அதே இயந்திரம், அதே 204 RPC-களுடன். அதைப் பெற எங்களைத் தொடர்பு கொள்ளுங்கள். இது தேவைப்படும் வணிகமற்ற அமைப்புகளுக்கும் பொருந்தும்: அதை நிறுவவும் அமைக்கவும் நாங்கள் உதவ முடியும். jesung@gamakon.ai அல்லது andrew@gamakon.ai.

## AI உதவியாளருடன் இயக்குவது

இந்தக் களஞ்சியத்தில் ஒரு MCP சேவையகம், `mcp/ultradim_mcp_server_v0_4_0.py`, வழங்கப்படுகிறது; இது தரவுத்தளத்தை 46 கருவிகளாக Claude Code, Codex அல்லது MCP பேசும் எந்த உதவியாளருக்கும் வெளிப்படுத்துகிறது. பின்னர் உதவியாளர் உங்கள் சார்பாகத் தரவுத்தளத்தை இயக்குகிறது: குடும்பத்தை (family) உருவாக்குகிறது, உங்கள் வெக்டர்களை உள்ளீடு செய்கிறது, அட்டவணையைக் கட்டமைக்கிறது, தேடுகிறது, கொத்தாக்குகிறது, வரைபடமாக்குகிறது, முடிவுகளை உங்களுக்கு வாசித்துக் காட்டுகிறது. நீங்கள் ஆய்வை விவரிக்கிறீர்கள்; அது அழைப்புகளைச் செய்கிறது.

wheel-ஐ நிறுவி, இந்தக் களஞ்சியத்தை clone செய்து, அந்த clone-இல் ஒரு உதவியாளர் அமர்வைத் திறக்கவும். Claude Code-க்கு, மூல அடைவிலுள்ள `.mcp.json` சேவையகத்தைப் பதிவு செய்கிறது; Codex-க்கு, `~/.codex/config.toml`-இல் இதைச் சேர்க்கவும்:

```toml
[mcp_servers.ultradim]
command = "python3.12"
args = ["/path/to/UltraDim/mcp/ultradim_mcp_server_v0_4_0.py", "--db", "/path/to/your/db"]
```

`command` என்பது wheel நிறுவப்பட்டுள்ள Python-ஆக இருக்க வேண்டும். பின்னர், வார்த்தைகளில் கேளுங்கள்: "இந்தக் கோப்பிலுள்ள வெக்டர்களை UltraDim-இல் ஏற்று, அவற்றைத் தேடக்கூடியதாக்கி, எனக்கு ஒரு வரைபடத்தைக் காட்டு." உதவியாளரின் முதல் அழைப்பு `whats_available` கருவியாக இருக்க வேண்டும்; அது ஒவ்வொரு கருவியையும், வழக்கமான வெற்றிப் பாதையையும் (happy path) wheel-இலிருந்து நேரடியாகப் பட்டியலிடுகிறது. முழு வழிகாட்டி [`mcp/README.md`](../mcp/README.md) (ஆங்கிலத்தில்).

## இதைக் கொண்டு நீங்கள் என்ன செய்யலாம்

**மிக அகலமான தரவைத் தேடி, பதில்களை நம்புங்கள்.** UltraDim உங்கள் தரவை அதன் இயல்பான அகலத்தில் கையாளுகிறது — மூலக்கூறு விரல்ரேகைகள் (fingerprints), சில்லறை வணிகக் கூடைகள், one-hot மரபணுவியல், உரை உட்பொதிவுகள் — உங்கள் பக்கத்தில் அம்சத் தொகுப்பாக்கமோ (feature hashing) துண்டிப்போ (truncation) இல்லாமல். நீங்கள் பெறும் மதிப்பெண்கள் உங்கள் மூல வெக்டர்களுக்கு எதிரான உண்மையான cosine-கள்; மேலும் அட்டவணை தேவைப்படும்போது தனது சொந்த வேட்பாளர் recall-ஐ துல்லியமான முழுத் தேடல் பதில்களுக்கு எதிராக அளவிடுகிறது; இதனால் ஒவ்வொரு தரவுத்தொகுப்பும் ஒரு நம்பிக்கையுடன் அல்ல, ஒரு தரச் சான்றிதழுடன் வருகிறது.

**30M-பரிமாணத் தரவின் உயிருள்ள 2-D வரைபடங்களைக் கட்டமையுங்கள்.** UMAP வரைபடங்கள் சேவையகத்திலேயே இயல்பாகக் கணக்கிடப்படுகின்றன — எனவே, வழக்கமான கருவிகள் தரவை ஏற்றவே முடியாத அகலங்களிலும் வரைபடக் கட்டமைப்பு வேலை செய்கிறது. வரைபடங்கள் உயிருள்ள பொருள்கள்: புதிய புள்ளிகள் ஏற்கனவே உள்ள வரைபடத்தில் மில்லிவினாடிகளில் இடம்பெறுகின்றன, சிறிய தொகுதிகள் மறுகட்டமைப்புச் செலவின் ஏறத்தாழ 1.5%-இல் இணைந்துகொள்கின்றன, மேலும் வரைபடத்தின் பதிப்பு வரலாறு உங்கள் தரவு ஓட்டத்திற்கான நகர்வுக் (drift) கண்டறிவியாகவும் செயல்படுகிறது.

**அகலத்துடன் போராடுவதற்குப் பதிலாக அதைப் பயன்படுத்தும் பகுப்பாய்வுகளை இயக்குங்கள்.** பொருத்தப்பட்ட வரைபடத்தின் மீது புதிதாக வருபவற்றின் புதுமை மதிப்பெண்ணிடல்; ஒதுக்கிவைக்கப்பட்ட மதிப்புகளை நேரடியாக அட்டவணையிலிருந்து மீட்டெடுக்கும் காரணியாக்கம்; செயற்கைத் தரவு உருவாக்கமும் சிறுபான்மை-வகுப்பு மிகைப்படுத்தலும்; தொகுப்புப் பகுப்பாய்வு; பிற்சேர் கருவிகளுக்கான ஏற்றுமதிகள்.

## ஆராய்ச்சிக் குழுக்களுடன் பணியாற்றுதல்

UltraDim உண்மையான அறிவியல் பணிச்சுமைகளின் மீது ஆராய்ச்சிக் குழுக்களால் பயன்படுத்தப்படுகிறது — மூலக்கூறு உருவகங்கள், மரபணு மற்றும் மேல்மரபணு (epigenomic) விவரக்குறிப்புகள், மற்றும் பெரிய கண்காணிப்பு அணிகள் (observational matrices). ஆராய்ச்சிப் பயன்பாடு வணிகமற்ற உரிமத்தின் கீழ் இலவசம்; wheel-ஐப் பதிவிறக்கித் தொடங்குங்கள். ஒரு நல்ல திட்டத்தில், உயர்-பரிமாணமான, பெரிய, விரல்விட்ட, அல்லது தற்போதைய கருவிகளால் பகுப்பாய்வு செய்ய மெதுவான ஒரு தரவுத்தொகுப்பு; நியாயப்படுத்தக்கூடிய ஒரு வெக்டர் உருவகமும் அளவீட்டு முறையும் (metric); மற்றும் மீட்டெடுப்பு, கூட்டுக் குழு (cohort), கொத்தாக்கம் அல்லது காட்சிப்படுத்தல் தொடர்பான ஒரு கேள்வி இருக்கும்.
